\# Parking Lot — Low-Level Design



A Java implementation of a Parking Lot system designed to practice Low-Level Design (LLD) concepts.



\## Features



\- Vehicle and parking spot modelling

\- Multiple parking floors

\- Vehicle-to-spot compatibility

\- Parking ticket generation

\- Active ticket tracking

\- Parking fee calculation

\- Entry and exit handling



\## Concepts Practiced



\- Object-Oriented Programming (OOP)

\- Single Responsibility Principle (SRP)

\- Encapsulation and separation of concerns

\- Constructor-based dependency injection

\- Basic concurrency handling

\- Error handling and state management
